# アイコン最終調整 — Issue #277

対象はビジュアライザの記号。操作UIは既存のPrimer Octiconsを使う。競技上の役割と色割当は変えない。

主要family（ridge）の12記号を調整した。車体と車輪、補給車の荷台、屋台の屋根・扉、器の縁、鍋の取っ手と注ぎ口、店のカウンター、旗付き露店の形を整理する。代替familyのしずくの下端と階段状の山の形も修正する。

全36記号のalpha面積重心を16×16座標の中心へ合わせ、外接範囲が少なくとも1.25unitの余白を残すようにする。最終確認は実際の64px共通atlasの画素を測り、重心の各軸誤差0.2unit未満・余白1.25unit以上を確認する。面積の数値は識別性や美しさの判定そのものではない。15px/24px/48pxの変更前後標本を目視で確認する。

凡例とマップに別の記号を持たせない。canonical proposalの標本から作る同じ形をhexfieldへ32unitで合成する。マップ用の白いcasingは視認性のために加え、形状本体を変形しない。抽出スクリプトは6cellの各wrapperから共通構造を取り出し、生成JSONとの一致を確認する。GPU/Canvasの共有atlas・六辺の黒線と白い余白・カメラ更新時の再転送不在を維持する。

確認資料はPR #278の `docs/design/reviews/pr-278/` に保存する。元の標本はマージ済みPR #276のcommit `9b6dd85282d85d6fb0608f79808d812763380bcb` に固定し、比較基準が後から変わらないようにする。

最終検証: `cbd0a2b` でfrontend型チェック・lint・format・単体10件・build成功。ブラウザ20件成功（4録画、全36記号の実atlas重心/余白、15pxの系列識別、GPU/Canvas比較、六辺の黒線と白い余白を含む）。canonical抽出一致も成功。
