# UI 再構築 #271 — 実装と検証

release-0-2-0 の placeholder を Primer の Home / Replays / Solvers / Live に置き換える。PR #272、branch `271`。専用 worktree `/tmp/procon-ui-271` で実装し、別セッションの branch `267` は変更していない。

## 実装した挙動

- Primer の theme、1行ナビ、12列 workspace、情報単位の Box、Octicons。固定SVGも JSX の要素・属性から描画し、`innerHTML` は使わない。
- SVG hex fixture、地形・6系列・agent のモチーフ。ridge は仮採用で、family の最終選定ではない。
- pan / zoom / reset、地図のキーボード操作。
- Solvers の SVG / WebGPU 切替。GPU はセルを instanced rendering し、境界・モチーフは SVG に重ねる。両者は同じ座標と Primer token を参照する。
- GPU 初期化失敗・5秒の timeout・device loss では SVG fallback。初回描画を読み戻し、背景だけの `blank-frame` も fallback。離脱・切替時に GPU resource を破棄する。
- 5 step の demo replay、再生・停止・速度・step・scrub と score。Space、矢印、Home/End、1/2/4 は viewer 内で有効。native control・map のキーを奪わない。
- scrub 中は timer を止め、release で元の再生状態へ戻す。Escape / pointer cancel は開始時の step に戻す。range の id は instance ごとに生成する。
- CLI `/match-state.json` を1秒周期で取得。重複リクエストを防ぎ、離脱時に abort。
- 5秒間初回データが得られない場合は No data。最後の成功取得から5秒以上経った場合は Stale。wire の `lastUpdateUnix` は Stale の基準ではない（`ux.html` section 03）。最後の成功値と error を維持する。
- wire status は Idle / Running / Completed / Error として表示。timestamp 0 は `00:00:00`。
- light / dark と localStorage、狭い viewport の overflow 防止。

## Toolchain の互換性修正

ベースの TypeScript 7 は旧 JS API を持たず、typescript-eslint が起動時に拒否していた。`typescript` は lint 用の 6.0.3、`typescript-native` は npm alias の 7.0.2 とし、check / build は後者の compiler を明示する。型チェック用 compiler は維持し、ルールの無効化・抑制はしていない。lock は `bun install` で更新した。

Chromium の headless GPU は ANGLE と Vulkan の両方を SwiftShader に指定する。アプリと独立した最小描画で元の設定による device loss を再現し、新設定で描画できることを確認した。実機 GPU の性能・ドライバー互換性の証明ではない。
