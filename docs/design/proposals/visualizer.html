1. Map colour — Primer data-vis assignment

地形塗りは data.<hue>.color.muted、符号と hex 境界は data.<hue>.color.emphasis（Primer 規則: emphasis = 線/境界、muted = 面塗り）。 data 色を semantic 用途（success/danger 等）に流用しない。符号に採用したのは level-5 emphasis の hue のみ — level-4（yellow / orange / green / gray / teal）は地形塗りに対し 2.7–2.9:1 と 3:1 の图形用下限を満たさないため符号には不採用。地形境界の green/gray 同色組も 2.8:1 だが、境界はページ地面との対比で ≥3:1 を確保し、識別は fill の色相 cue が担う。

Contrast は WCAG relative-luminance 比。符号の値は「その符号が乗る 4 地形 muted 塗りすべて」に対する最小値 （地形間の差は 0.05 以内）。图形用 3:1 を全組で満たす。系列の隣接識別は形状 cue と併用（WCAG 1.4.1 色だけに依存しない）。 系列の最小隣接 ΔE(Lab) = 16.0（s3 purple – s4 plum）で、他は 25 以上。採用色相の意味対応: s0 gold→lemon, s1 burnt→coral, s2 brick→auburn, s3 violet→purple, s4→plum, s5 leaf→lime, patrol→pine, supply→pink。

2. Hex field at real size — light and dark

light

dark

hex は pointy-top・実サイズ相当（flat-to-flat 15px）。地形 texture: plain = ドット pitch 2.5px / radius 0.75px（15px hex 当たり ≒ 6×6 粒）。旧値 pitch 1.4px / r 0.3px は 15px でドットが潰れて tone になるため失格 — 48px 併記で拡大時の粒も確認する。mountain = hatch 30° from horizontal（pointy-top hex の辺方向 30° / 90° / 150° のうち 30° に平行＝右上/左下エッジ族（edge slope 26:15 と同斜率）。旧 45° はどの辺とも非平行で不採用）。water = 波、road = 帯。

3. Visualiser marks — 3 motif families

意味が違う符号は形も違う（WCAG 1.4.1 の形状 cue）。漢字 overlay は既定 OFF。 上段 44px = 拡大検証、下段 15px = 実サイズ。色は §1 の data-vis 割当。hex 囲み border は維持。

ridge — Ridge / Wave / Band

peak — Peak / Droplet / Ribbon

terrace — Step-peak / Level-gauge / Lane

最小可読サイズ規格（実サイズ 15px 描画時）: ink bbox 長辺 ≥ 10.5px・短辺 ≥ 5.5px・線幅 ≥ 1.3px。 実測の最小 bbox は 10.7 × 10.6px（ridge-s2）。規格未満だった描画（旧 s2 の湯気線・s3 のつまみ・s5 の旗竿など）は太らせて引き起こし済み。
