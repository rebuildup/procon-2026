## 3. 禁止事項（破ると失敗）

1. **project 独自のトークン値を作らない** — Primer にある値は参照する。書き写さない
2. **自前のデザインシステム（トークン表・component gallery・typography scale）を作り直さない** — v5 で**撤廃済み**。Primer がそれ
3. **`design-system.html` を復活させない** — 廃止済み
4. **Octicons を独自描画で置き換えない** — UI icon は Primer Octicons。**例外は `play` のみ**（Octicons に無いので `triangle-fill` を使う）。`skip` は「円＋斜線」で dependency skip の意味なので**使わない**
5. **ビジュアライザの記号に Octicons を使わない** — 記号はモチーフ起点の独自設計（山→稜線、水→波、道路→帯、巡回→巡回、補給→補給）。抽象幾何（三角・菱形）は意味を運ばないので禁止
6. **external リクエストを発生させない** — CDN / web font / 画像 / icon font を使わない
7. **数字の乱高下で階層を作らない** — HUD / match-state は **label 11px + value 15px の 2 段のみ**
8. **カードの一部にアクセント色を塗らない** — 左端・上端・角の色帯、accent border を含む。これは AI 的紋切り型として禁止
9. **ナビに左の accent バーを生やさない** — 現在地は選択 tone + 太字 + icon
10. **サイドバーの項目を 2 行にしない** — `icon + label` の 1 行のみ。メタ情報（例 `1 / 4 · [2, 3]`）は右側の情報パネルへ

## 4. GitHub / Primer の構造規則（見た目だけでなく構造も揃える）

- **box は「1 つの単位」のときだけ囲む。** box の中で box を重ねず、**行 + hairline** で分ける
- **右側の情報レールは囲む** — 情報の単位 = 1 box、中に**単位の題名**を 1 つ（About / Releases 相当）。これは残す
- **消すのは「言い換えの装飾」** — box の外や隣に付く micro-caps、役割ラベル、値の繰り返しタグ
- **1 行にできる情報は 1 行にする**。2 行に分かれていて 1 行で完結するものを畳む
- **グリッドは 1 系統** — `repeat(12, minmax(0, 1fr))`、gap は Primer `space`。ネスト grid は `grid-column: 1 / -1` で親に spanning し、**親より広い要素を作らない**

## 5. 実装層（proposal を書くときもこの語彙で）

| 用途 | パッケージ | 扱い |
|---|---|---|
| 見た目 | `@primer/css` 22.x | class をそのまま載せる（`Box` `Box-header` `btn` `Label` `Subhead` `Truncate` 等） |
| トークン | `@primer/primitives` | CSS カスタムプロパティとして**参照** |
| icon | `@primer/octicons` 19.x | **inline SVG**。`currentColor` 継承。path は最小改変 |
| 行動 | `@kobalte/core` 0.13.x | SolidJS 専用・unstyled。Primer class を乗せる |

**Primer に SolidJS ポートは無い**（`@primer/octicons-react` / Rails 系のみ）。だから**フレームワークに依らない層だけ**を使う。これが v5 と整合する。

疎通確認は PR #270 で **4 点とも実証済み**（Primer CSS 適用・トークン解決・Octicon の currentColor 継承・Kobalte のトグル）。実装前に `src/spike/PrimerSpike.tsx` を見るとよい。

**theme の scoping に注意**: Primer の意味色は `@primer/primitives/dist/css/functional/themes/*.css` にあり、`[data-color-mode]` + `[data-*-theme]` で scoping される。`<html>` に属性が必要（`packages/frontend/index.html` に設定済み）。
**Primer は 14 テーマを同梱**している — light / dark / dark-dimmed に加え **colorblind / tritanopia / high-contrast** の各 variant。色覚多様性への対応は自前で作らない。
