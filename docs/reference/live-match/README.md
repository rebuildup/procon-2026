# 公式動作確認サーバーでのローカル対戦

公式配布の `procon-server-linux-amd64` に2チームの行動計画を送り、4日間の対戦を実行した画面です。Q6の表の再生ではなく、サーバーが処理したHTTP応答をLive画面に接続しています。大会・練習場の実戦ログではありません。

盤面は公式 `example.json` の10×10マップです。撮影時間を短くするため、各日の受付時間だけ30秒から12秒へ変更しました。一方のチームは毎日1回左右へ移動して残りを待機し、他方は待機します。両チームとも4日分の行動計画が受理されています。競技用ソルバーの評価ではなく、通信・表示の確認用の対戦です。

| 動画 | 内容 |
|---|---|
| [通常表示](live-desktop.webm) | WebGPU、ホバー・選択解除、操作欄のスクロール、日ごとの更新、モバイル幅への切替、Stale |
| [Canvas・ダーク表示](live-canvas-dark.webm) | Canvasフォールバック、ダークモード、ホバー・選択解除、操作欄のスクロール、ズーム・パン・リセット、Stale |

GIFは各動画の冒頭24秒を720×500・2フレーム/秒に変換したプレビューです。動画全体には対戦開始から終了・通信断までを収録しています。

[受信した設定・日次状態](match-data.json)、[移動チームの提出・受理結果](team-0-plans.json)、[待機チームの提出・受理結果](team-1-plans.json)、[実行条件・バイナリのハッシュ](source.json)、[録画環境](manifest.json)を保存しています。認証トークンは含みません。

APIが返すのは日初めの状態です。動画でも1日ごとの位置の変化を表示し、ステップ内の移動は補間していません。

`live-inspection.png` は情報表示の追加後に公式サーバーで再度実行したローカル対戦を撮影したものです。この確認用対戦では各日の受付時間を10分に設定しています。盤面の燃料ゲージ、回答締切、対象ヘキサに隣接するホバー詳細を表示しています。
