混乱を避けるため、ここに明文化します。

## 並走ルールの要点

- **同期しない**: 本リポは fork ではないし、主導トラックの実装を取り込む予定もない。
- **戦略は独立に再考**: 主導トラックの日記・戦略メモは **CONFIDENTIAL 扱い**。
  取り込みたい要素はあくまで「着想」レベルまで咀嚼し、本リポの文書は **オリジナルの分析** として書く。
- **公式資料のPDFは共通**: `docs/pdf/` 配下は両トラックで参照してよい原本PDF。
- **本選提出物は別**: 最終的に提出するシステム・応募資料は代表として1セットのみ用意する。
  提出直前まで、どちらのトラックを採用するかは確定しない。

## CONFIDENTIAL フラグの扱い

主導トラック側に存在する `@@CONFIDENTIAL@@` マーク付きの日記や、写経された公式資料 Markdown
（`docs/src/official/*.md` 等）は、**大会終了まで取扱注意** と元文書に明記されている。
本リポへ取り込む場合は、以下を遵守する:

1. **日記・戦略メモ** は原則取り込まない（並走ルール上の競合を避ける）。
2. **公式資料** は `docs/pdf/` のPDF原本を正とする（写経は正本ではない）。
3. **例外手順（2026-10-08 開始・Issue #309 で最初に行使）**: 取り込む必要が出た素材は、
   原著作者クレジットと `@@CONFIDENTIAL@@` フラグの明示（マークは削除しない）を provenance
   に記載したうえで `docs/reference/` 配下へ取り込める。取り込み済み:
   `docs/reference/official-md/`・`docs/reference/procon2026-diary/`・`docs/reference/live-match/`。
4. 取り込んだ資料を本リポの文書へ転載しない — 着想の参照と本リポ独自の分析として書く
   （並走ルール「戦略は独立に再考」は維持）。
